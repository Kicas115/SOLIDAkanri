# SOLIDAkanri

## CSVからのインポート

画面右上の「CSVからインポート」からCSVファイルを選択します。ヘッダーは `ID,ステータス,タイトル,仕入値(円),売価(円),利益(円),ラベル` を含めてください（列順は問いません）。UTF-8とShift-JISに対応し、ステータスは「積読」「読了」「搬入する」「搬入済み」「売れた」のいずれかを指定します。

有効な行を既存データに追加します。同じIDはスキップし、ID・タイトルが空欄の行、無効なステータスや金額の行は取り込みません。「ラベル」はデータに保存しますが、現在の画面では表示しません。CSVの「利益(円)」は保存せず、アプリで仕入値・売価・経費率から計算します。
